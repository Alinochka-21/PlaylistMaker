Основные моменты: 
- SearchQuery - обертка для "отправки" запроса
- TracksResponse - обертка для "получения" ответа от сервера 
- iTunesApi - интерфейс с методом-запросом
- метод showErrorPlaceholder - отвечает за отображение заглушек 
- метод performSearch - отвечает за отправку запроса клиента и обработку ответа 
- editText.setOnEditorActionListener - слушатель эдиттекста
- updateButton.setOnClickListener - слушатель кнопки обновить
