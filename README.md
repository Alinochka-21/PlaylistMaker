14 спринт: 
Основные моменты: 
- в SearchActivity:
    - canPressOnTrack - отвечает за состояние элемента в списке(сделает ли он что-то при нажатии или нет)
    - mainThreadHandler - хендлер, чтобы отправлять методы в главный поток
    - progressBar - прогрессбар для имитации загрузки ответа от сервера (у него меняем visible)
    - searchRunnable - тут будет храниться код для отправки в главный поток 
    - метод clickDebounce() - отвечает за смену состояния canPressOnTrack (true->false->true) и отвечает за "активацию" возможности нажатия на элементы списков
    - метод searchDebounce() - отвечает за то, чтобы стереть неактуальный запрос из потока и отправить актуальный 
    - константы для методов: SEARCH_DEBOUNCE_DELAY, CLICK_DEBOUNCE_DELAY
- В AudioPlayerActivity:
    - метод prepareMediaPlayer() - подготовка аудиоплеера
    - playTrackButton - кнопка играть/пауза
    - currentTimeTrack - вью таймера
    - метод playTrack() - активация трека
    - метод pauseTrack() - остановка трека
    - метод playTrackButtonControl() - переход состояний кронки играть и пауза 
    - startTimer() - меняет цифры на таймере
